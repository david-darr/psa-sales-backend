## Runtime

On Render (`RENDER=true`), the web service defaults to the tested in-process durable worker. Explicit OUTREACH_WORKER_MODE remains respected; CLI workers force external mode. Saved leases, reviews, caps, canonical-recipient reservations, cancellation and unconfirmed outcomes remain enforced. Replies are checked in fair bounded turns. Old day-3/day-7 automatic sending is retired in this release. Campaign automation remains off until deliberate acceptance and configuration.

Supabase Cron/pg_net wakes the existing backend every five minutes only when there is a due batch, eligible sequence work, an authorized scheduled/running campaign, or a stale/unfinished mailbox check. No idle keep-alive request is made. The narrow wake credential lives in Vault; only its hash is in an RLS-protected application table. The trigger cannot approve, address or alter messages. Cron/HTTP/cold-start failures can delay work; there is no guaranteed exact-time delivery or unlimited free-tier capacity. Monitor platform usage and existing quotas. Do not purchase a plan or enable paid overages.
